## Cloud Agent

- After `npm ci`, run `npx next typegen` before `npx tsc --noEmit`. `LayoutProps` is generated by Next.js and is not committed.
- Start the app with `npm run dev -- --hostname 0.0.0.0 --port 3000`.
- Run the agent test suite with `node src/agent/__tests__/runner.mjs`. There is no `npm test` script. Lint with `npm run lint` and build with `npm run build`.
- Voice secrets are optional for local development: `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_AGENT_ID_EN`, and `ELEVENLABS_VOICE_AGENT_ID_ES`. Without them, `POST /api/voice/session` returns 503 and the caller can continue by typing. See `src/voice/README.md`.
- The voice route accepts a browser request only when the `Origin` header equals `request.nextUrl.origin`. With the dev server bound to `0.0.0.0`, open `http://0.0.0.0:3000` so that origin matches.
